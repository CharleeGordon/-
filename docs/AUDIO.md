# Звук и музыка

Всё синтезировано скриптом `game/tools/gen_audio.py` (фортепиано, музыкальная шкатулка, струнные, хор, клавесин Карплуса–Стронга, медь, тайко, реверберация зала). Любой файл можно заменить настоящей записью с тем же именем.

## Лейтмотив
«Пембертонский вальс» — ре минор, 3/4. Звучит в каждом треке в разной обработке: шкатулка (меню), обрывки на фортепиано (обход), медь (погоня/финал), клавесин (Герцогиня), свист (Гэри), мажорный лаунж (офисное радио).

## Треки и когда играют (autoload `Music`)
| Состояние | Файл | Триггер |
|---|---|---|
| menu | menu_theme | главное меню |
| calm | explore_calm | начало ночи |
| tense | explore_tense | после блэкаута / поздняя ночь |
| blackout | blackout | нет электричества |
| storm | duchess_theme | ночь 3 |
| danger | danger_near | рядом угроза (рыцарь/Гэри близко, взгляд Герцогини) |
| chase | chase | погоня (мумия, Вольфганг, Гэри) |
| silence (радио) | office_radio — звучит из радио в офисе | игрок в безопасной зоне |
| finale | finale | ночь 5 после того, как взяли Утку |
| dawn / credits | dawn, credits | конец ночи, концовки, титры |

Приоритет: **погоня > опасность > офис > настроение ночи**. Переходы — плавные кроссфейды (погоня врубается за 0,5 с, уходит за 3 с).

**Стингеры:** начало ночи, удар часов каждый час, «рыцарь сдвинулся», задача выполнена, выговор (грустный тромбон), раскрытие сюжета, скример, смерть.

**Без музыки:** сердцебиение и дыхание игрока ускоряются от уровня угрозы, звуки приглушаются в шкафу, шаги зависят от пола, случайные скрипы и далёкие шаги вокруг, реверберация залов.
