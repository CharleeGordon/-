# Чек-лист плейтеста

Дайте игру человеку, ничего не объясняя. Молча смотрите. Запишите:

**Понятность**
- [ ] Понял, что делать в первые 30 секунд?
- [ ] Нашёл часы для отметки, правила, фонарик?
- [ ] Открыл журнал (Tab)?
- [ ] Понял правило рыцаря до первой смерти?

**Страх / смех**
- [ ] Где испугался? (время по часам в игре)
- [ ] Где засмеялся?
- [ ] Было ли скучно? Где?

**Баланс**
- [ ] Сколько раз умер и от кого?
- [ ] Хватило батареек?
- [ ] Дожил до 6:00 с какой попытки?
- [ ] Сколько выговоров и за что?

**Баги**
- [ ] Застревал в стенах/предметах?
- [ ] Монстр застрял или вёл себя странно?
- [ ] Что-то не нажималось?

**После игры спросить:** «Что запомнилось больше всего?» и «Сыграл бы ещё ночь?»
