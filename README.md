# Do Not Touch the Exhibits
*(«Экспонаты руками не трогать»)*

First-person survival horror comedy для Windows / Steam. Вы — новый ночной охранник в «Пембертонском музее сомнительной истории». После закрытия экспонаты оживают, а начальница Бренда по рации знает о музее больше, чем говорит.

**Статус:** версия 0.3 — 5 ночей (~60–90 минут), музей на 3 этажа (20 залов), озвученный сюжет, 2 концовки.
**Движок:** [Godot 4.5](https://godotengine.org/download) (бесплатный, без отчислений).
**Графика, музыка и звуки** сгенерированы программно (без чужих ассетов → нет проблем с лицензиями). Для релиза их можно заменить на работы художников и композитора, не трогая код — имена файлов те же.

---

## Как поиграть

**Готовый .exe (ничего устанавливать не нужно)**
1. На GitHub: вкладка **Actions** → последний запуск **Build Windows** (зелёная галочка).
2. Внизу, в **Artifacts**, скачайте `DoNotTouchTheExhibits-windows`, распакуйте, запустите `.exe`.
3. Если Windows покажет синее окно — «Подробнее» → «Выполнить в любом случае» (exe пока не подписан).

**Через Godot (для разработки):** Godot 4.5 → **Import** → `game/project.godot` → **F5**.

## Управление

| Клавиша | Действие |
|---|---|
| Мышь | осмотреться |
| WASD | ходить |
| Shift | бежать (шумно!) |
| Ctrl / C | присесть (тихо) |
| F | фонарик |
| R / ПКМ | вспышка фотоаппарата (оглушает экспонаты) |
| G / СКМ | бросить пищащую уточку (отвлекает) |
| E / ЛКМ | использовать, спрятаться в шкафчик / выйти |
| Tab / J | журнал: задачи, правила, выговоры, найденные документы |
| Esc | пауза и настройки |
| F11 | полный экран |
| F9 | *(только в Godot)* перемотать час — для тестов |

Поддерживается геймпад (Xbox-раскладка).

## Что в игре

**Музей:** 3 этажа, 20 залов. Первый этаж (лобби-атриум, галерея, Египет, динозавры, восковые фигуры, кунсткамера, склад), второй (библиотека, планетарий, естествознание, оружейная, мастерская, костюмы, кабинет директора, комната кукол), подвал (котельная, архив, хранилище основателя). Этажи открываются постепенно.

**Ночи**
1. **Orientation** — рыцарь, мумия, застенчивый тираннозавр, блэкаут (рубильник — в подвале), кража Золотой Утки.
2. **Clockwork** — заводной Вольфганг, лампочки, меч рыцаря, второй этаж, фотоаппарат, Чаепитие кукол.
3. **Portrait Night** — гроза, окна, книги в библиотеке, моль (выключи фонарик!), сеанс в планетарии в 3:00, Герцогиня.
4. **The Other Guard** — Гэри патрулирует оба этажа, отключённый свет, пищащие уточки, архив и личное дело Бренды.
5. **Closing Time** — правда об Утке, Бренде и её дочери Люси; основатель сэр Арчибальд в подвале; выбор концовки.

**Механики:** часы 0:00→6:00 (10 мин на ночь), задачи, правила и выговоры, фонарик с батареей, выносливость, приседание и шум, шкафчики, камеры, фотоаппарат со вспышкой (плёнка ограничена), уточки-приманки, скриптовые пугалки, болтовня Бренды по рации, контрольная точка в 3:00, 17 записок и 12 аудиокассет (эффекты кассеты, граммофона, автоответчика, дрожащий голос), сохранение, геймпад, настройки графики (на High включается глобальное освещение SDFGI).

**Звук и музыка:** вся музыка построена на одной теме («Пембертонский вальс») и переключается по ситуации: спокойствие → напряжение → опасность → погоня, свои темы для второго этажа, подвала, грозы, блэкаута, финала, тема Бренды (вальс в мажоре, колыбельная) и погоня основателя (орган). Все реплики озвучены (временные голоса Piper TTS, рация/граммофон).

Подробнее — [docs/GDD.md](docs/GDD.md), звук — [docs/AUDIO.md](docs/AUDIO.md), план — [docs/ROADMAP.md](docs/ROADMAP.md), плейтест — [docs/PLAYTEST.md](docs/PLAYTEST.md).

## Структура проекта

```
game/
  autoload/      Save (настройки, прогресс), Music (адаптивная музыка), Shift (состояние ночи)
  scripts/
    game.gd      запуск ночи, взаимодействия, смерть, контрольная точка
    nights/      сценарии ночей night_1.gd ... night_5.gd   <- тексты, события по часам, пугалки
    enemies/     рыцарь, мумия, динозавр, автомат, Герцогиня, Гэри, куклы, моль, основатель
    player.gd    игрок        hud.gd  интерфейс        data/notes.gd, tapes.gd  записки и кассеты
  scenes/        museum.scn (сгенерирован), game, player, main_menu, credits
  textures/ materials/ audio/   сгенерированные ассеты (заменяемые)
  tools/         генераторы: gen_textures.py, gen_audio.py, gen_voice.py, build_world.gd (+ meshlib, props)
  tests/         автотест всех ночей, скриншоты
```

## Для разработчика

```bash
cd game
python3 tools/gen_textures.py        # текстуры        (pip install numpy pillow)
python3 tools/gen_audio.py           # музыка и звуки  (pip install numpy scipy soundfile)
python3 tools/gen_voice.py           # голоса (pip install piper-tts; PIPER_MODEL=путь к en_US-libritts-high.onnx)
godot --headless --path . --import
godot --headless --path . res://tools/build_world.tscn   # пересобрать музей (ПЕРЕЗАПИСЫВАЕТ museum.scn)
godot --headless --path . res://tests/smoke_test.tscn    # автотест: 5 ночей, 99 проверок
```
