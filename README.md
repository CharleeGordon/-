# Do Not Touch the Exhibits
*(«Экспонаты руками не трогать»)*

First-person survival horror comedy для Windows / Steam. Вы — новый ночной охранник в «Пембертонском музее сомнительной истории». После закрытия экспонаты оживают.

**Статус:** MVP vertical slice (~10 минут игры), графика и звук — заглушки.
**Движок:** [Godot 4.5](https://godotengine.org/download) (бесплатный, без отчислений, экспорт в Windows).

---

## Как поиграть

**Вариант 1 — готовый .exe (без установки чего-либо)**
1. На GitHub откройте вкладку **Actions** → последний запуск **Build Windows**.
2. Внизу, в разделе **Artifacts**, скачайте `DoNotTouchTheExhibits-windows`.
3. Распакуйте и запустите `DoNotTouchTheExhibits.exe`.

**Вариант 2 — через Godot (для разработки)**
1. Скачайте Godot 4.5 (Standard, не .NET) и запустите.
2. **Import** → выберите файл `game/project.godot` → **Import & Edit**.
3. Нажмите **F5** (▶ в правом верхнем углу).

## Управление

| Клавиша | Действие |
|---|---|
| WASD | ходить |
| Shift | бежать (тратит выносливость) |
| F | фонарик (тратит батарею) |
| E | использовать |
| Tab / J | журнал: задачи, правила, выговоры |
| Esc | пауза |
| F11 | полный экран |
| F9 | *(только в Godot)* перемотать на час вперёд — для тестов |

## Что в MVP

- Одна ночь: 00:00 → 06:00 = 10 реальных минут.
- 6 залов: офис охраны (безопасная зона), холл, склад, галерея, египетский зал, зал динозавров.
- Задачи: отметиться, прочитать правила, взять фонарик, обход 3 чекпоинтов, починить свет, вернуть Золотую Утку.
- 3 угрозы:
  - **Сэр Кланксворт** (доспехи) — двигается, только когда на него не смотрят.
  - **Мумия** — просыпается, если бежать в египетском зале.
  - **Джеральд** (скелет T-Rex) — ревёт, если светить ему фонариком в глаза.
- Правила музея + выговоры: 3 выговора = уволен.
- В 3:00 отключается свет, в 4:00 крадут утку, в 5:00 мумия просыпается сама.

Подробности — в [docs/GDD_MVP.md](docs/GDD_MVP.md). План дальше — [docs/ROADMAP.md](docs/ROADMAP.md). Чек-лист для плейтеста — [docs/PLAYTEST.md](docs/PLAYTEST.md).

## Структура проекта

```
game/
  project.godot        настройки проекта
  autoload/shift.gd    часы, задачи, выговоры, правила (глобальное состояние)
  scripts/game.gd      сценарий ночи: события по часам + что делает каждый предмет  <- тексты и тайминги здесь
  scripts/player.gd    игрок: ходьба, бег, фонарик
  scripts/knight.gd    рыцарь  | scripts/mummy.gd  мумия  | scripts/dino.gd  динозавр
  scripts/hud.gd       интерфейс, журнал, пауза, экран конца
  scenes/              сцены (museum.tscn — сам музей)
  audio/               звуки-заглушки (заменить файлами с теми же именами)
  tools/               генераторы музея и звуков
  tests/               автотест прохождения + скриншоты
```

## Для разработчика

```bash
cd game
godot --headless --path . --import                       # первый импорт
godot --headless --path . res://tests/smoke_test.tscn    # автотест (28 проверок)
godot --headless --path . res://tools/build_museum.tscn  # пересобрать музей (ПЕРЕЗАПИСЫВАЕТ museum.tscn)
python3 tools/gen_audio.py                               # пересоздать звуки-заглушки
```

`museum.tscn` сгенерирован скриптом. Как только начнёте править музей руками в редакторе Godot — больше не запускайте генератор.
