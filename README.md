# Do Not Touch the Exhibits
*(«Экспонаты руками не трогать»)*

First-person survival horror comedy для Windows / Steam. Вы — новый ночной охранник в «Пембертонском музее сомнительной истории». После закрытия экспонаты оживают, а начальница Бренда по рации знает о музее больше, чем говорит.

**Статус:** полная игра, версия 0.2 — 5 ночей (~60–90 минут), сюжет, 2 концовки.
**Движок:** [Godot 4.5](https://godotengine.org/download) (бесплатный, без отчислений).
**Графика, музыка и звуки** сгенерированы программно (без чужих ассетов → нет проблем с лицензиями). Для релиза их можно заменить на работы художников и композитора, не трогая код — имена файлов те же.

---

## Как поиграть

**Готовый .exe (ничего устанавливать не нужно)**
1. На GitHub: вкладка **Actions** → последний запуск **Build Windows** (зелёная галочка).
2. Внизу, в **Artifacts**, скачайте `DoNotTouchTheExhibits-windows`, распакуйте, запустите `.exe`.
3. Если Windows покажет синее окно — «Подробнее» → «Выполнить в любом случае» (exe пока не подписан).

**Через Godot (для разработки):** Godot 4.5 → **Import** → `game/project.godot` → **F5**.

## Управление

| Клавиша | Действие |
|---|---|
| Мышь | осмотреться |
| WASD | ходить |
| Shift | бежать (шумно!) |
| Ctrl / C | присесть (тихо) |
| F | фонарик |
| E / ЛКМ | использовать, спрятаться в шкафчик / выйти |
| Tab / J | журнал: задачи, правила, выговоры, найденные документы |
| Esc | пауза и настройки |
| F11 | полный экран |
| F9 | *(только в Godot)* перемотать час — для тестов |

## Что в игре

**Ночи**
1. **Orientation** — рыцарь, мумия, застенчивый тираннозавр, блэкаут, кража Золотой Утки.
2. **Clockwork** — заводная кукла Маленький Вольфганг: заводи его, пока играет музыка.
3. **Portrait Night** — гроза, открытые окна, Герцогиня: когда картины смотрят — замри.
4. **The Other Guard** — Гэри, пропавший охранник, теперь восковая фигура и всё ещё делает обход с фонарём.
5. **Closing Time** — правда о проклятой Утке, финальный забег через весь проснувшийся музей, выбор концовки.

**Механики:** часы 0:00→6:00 (10 мин на ночь), задачи, правила музея и выговоры (3 = уволен), фонарик с батареей, выносливость, шум шагов (монстры слышат бег), шкафчики, камеры видеонаблюдения, контрольная точка в 3:00, 12 сюжетных записок, сохранение прогресса, настройки (чувствительность, FOV, громкость, графика, сложность «Story»).

**Звук и музыка:** вся музыка построена на одной теме («Пембертонский вальс») и переключается по ситуации: спокойствие → напряжение → опасность рядом → погоня, отдельно блэкаут, гроза, финал, рассвет. Офисное радио играет ту же тему в мажоре как лаунж — это комедийная передышка в безопасной зоне.

Подробнее — [docs/GDD.md](docs/GDD.md), звук — [docs/AUDIO.md](docs/AUDIO.md), план — [docs/ROADMAP.md](docs/ROADMAP.md), плейтест — [docs/PLAYTEST.md](docs/PLAYTEST.md).

## Структура проекта

```
game/
  autoload/      Save (настройки, прогресс), Music (адаптивная музыка), Shift (состояние ночи)
  scripts/
    game.gd      запуск ночи, взаимодействия, смерть, контрольная точка
    nights/      сценарии ночей night_1.gd ... night_5.gd   <- тексты, события по часам
    enemies/     рыцарь, мумия, динозавр, автомат, Герцогиня, Гэри + общий ИИ и анимация
    player.gd    игрок        hud.gd  интерфейс        data/notes.gd  тексты записок
  scenes/        museum.scn (сгенерирован), game, player, main_menu, credits
  textures/ materials/ audio/   сгенерированные ассеты (заменяемые)
  tools/         генераторы: gen_textures.py, gen_audio.py, build_world.gd (+ meshlib, props)
  tests/         автотест всех ночей, скриншоты
```

## Для разработчика

```bash
cd game
python3 tools/gen_textures.py        # текстуры        (pip install numpy pillow)
python3 tools/gen_audio.py           # музыка и звуки  (pip install numpy scipy soundfile)
godot --headless --path . --import
godot --headless --path . res://tools/build_world.tscn   # пересобрать музей (ПЕРЕЗАПИСЫВАЕТ museum.scn)
godot --headless --path . res://tests/smoke_test.tscn    # автотест: 5 ночей, 72 проверки
```
